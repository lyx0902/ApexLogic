## 文档边界

每个主题只有一篇主文档。其他文档只说明调用关系，通过链接引用规则，避免多份文档分别维护同一流程。

- **执行**拥有任务生命周期；**存储**拥有连接、表和迁移。
- **检索**拥有搜索调度；**排序**拥有候选筛选；**评审**拥有报告接受判定。
- **来源记忆**拥有证据模型与召回；**记忆优先调度**拥有是否免搜的决策；**发布**拥有完成后的写入和诊断。
- **缓存**只拥有可丢弃的请求结果，不承担任务或长期记忆持久化。
- **使用**拥有启动和观察方法；**评测**拥有验收标准与实验口径。

## 维护约定

1. 源码链接使用相对路径，指向模块文件；函数名用于精确定位，避免行号随修改过时。
2. 修改模块行为时，只更新其主文档和必要的接口说明，不复制整个实现到相邻章节。
3. “默认值”区分未设置时的代码回退值与 .env.example 的示例值。
4. 模拟测试、真实服务集成测试、真实研究任务分别陈述；未运行的检查不写成已经通过。
5. 旧文档继续保留；遇到描述冲突时应核对代码，而不是根据文档日期推断实现。
6. 当前 .gitignore 对 docs 使用白名单；本目录的新文件可能被忽略。发布文档时须显式纳入版本管理，本次不调整忽略规则。
